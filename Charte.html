Tattoo Manager Charte v1
Direction artistique

Sobre, monochrome, et lisible au quotidien.

Même base que NOVA : un noir légèrement chaud, un blanc cassé, Geist, des bordures fines et une seule courbe d’animation. Deux thèmes, Ivoire la nuit et Jour le jour. Par défaut, l’app suit le réglage clair/sombre du système. Pas de mascotte.

Principes

Les règles qui tranchent quand on hésite.

Monochrome d’abord

Le contenu porte l’information. L’accent sert seulement aux actions principales et au focus.

Bordures, pas d’ombres

La profondeur vient de trois niveaux de surface et de lignes à 10 %. Une seule ombre, pour la fenêtre.

Dense mais calme

Un outil métier affiche beaucoup d’infos : texte en 13–14 px, mais de l’air entre les blocs.

Le mouvement informe

Une animation montre un état (hover, focus, ouverture). Jamais décorative, toujours sur la même courbe.

Couleurs

Des tokens sémantiques : on nomme le rôle, jamais la teinte. Les valeurs se mettent à jour quand tu changes de thème.

Changer de DA facilement

Trois niveaux de tokens. Pour une nouvelle DA, on ne touche qu’aux deux premiers.

1. Primitivesvaleurs brutes

Échelles de gris, couleurs, tailles. gray.950 = #0b0b0c. Aucun composant ne les utilise directement.

↓
2. Sémantiquespar thème

Le rôle : bg, surface, fg-muted, accent, danger. Un fichier par thème : Ivoire et Jour. Le mode Système choisit entre les deux selon l’OS.

↓
3. ComposantsReact + Tailwind

Les composants n’utilisent que les tokens sémantiques via Tailwind (bg-surface, text-fg-muted). Zéro couleur en dur.

# une seule source de vérité
src/styles/
  tokens/
    primitives.css
    themes/
      ivoire.css
      jour.css
  tokens.css  → React / Tailwind
/* tokens.css */
:root, [data-theme="ivoire"] {
  --bg: #0b0b0c; --accent: #ecebe6;
}
[data-theme="jour"] {
  --bg: #f6f5f1; --accent: #161614;
}
/* Système : suit l’OS */
@media (prefers-color-scheme: light) {
  :root:not([data-theme]) { /* = jour */ }
}
/* Tailwind v4 */
@theme inline {
  --color-bg: var(--bg);
  --color-accent: var(--accent);
}
